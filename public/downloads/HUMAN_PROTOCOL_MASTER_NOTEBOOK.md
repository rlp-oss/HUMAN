## 3. The 50% People's Covenant & Economic Model

### Automated Revenue Split Architecture
Every commercial SaaS, AI tool, writing platform, or media app in the H.U.M.A.N. Ecosystem operates on an immutable 50% revenue covenant:
- **50% App Operations & Infrastructure**: Covers server compute, development, hosting, and operations.
- **50% Society & Creator Fund**: Deposited directly into an unassailable escrow pool audited in real time.

### Payout & Distribution Logic
1. **Direct Creator Attributions (Pool A - 70% of Fund)**: Micro-royalties routed via Stripe Connect to verified human artists, musicians, writers, and software contributors whose work assisted or inspired an AI generation.
2. **Unregistered Holding Escrow (Pool B - 15% of Fund)**: Held in cryptographic trust for legacy and unregistered rights-holders with zero expiration forfeiture.
3. **Universal Community Living Floor & Healing (Pool C - 15% of Fund)**: Grants deployed for open-source health diagnostics, emergency relief, and civic education.

## 5. Technical Architecture & Implementation Stack

### Technology Stack
- **Frontend Framework**: React 18+ with TypeScript & Vite.
- **Styling**: Tailwind CSS with custom warm-neutral design tokens (Alabaster, Forest Emerald, Terracotta, Obsidian Dark).
- **Icons**: Lucide-react.
- **Backend API**: Node.js & Express with lazy-initialized SDK clients.
- **AI Engine**: Google Gemini API (`@google/genai`) for empathetic user interaction and document synthesis.
- **Payment & Escrow Rails**: Stripe Connect & webhook distribution processors.
- **Provenance & Trust**: C2PA metadata manifest generation and public ledger verification.

### Core Source Code Components
- `/src/components/PublicMissionWebsite.tsx`: The primary educational sanctuary for everyday citizens.
- `/src/components/HumanInitiativeRoadmapSite.tsx`: Canonical reference site for the 7-phase economic evolution roadmap.
- `/src/components/GlobalFundMacroAndBlockchainArchitecture.tsx`: Real-time macroeconomic ledger, multi-sig governance, and escrow math.
- `/src/components/CreatorPayoutDashboard.tsx`: Stripe Connect live payout console for human creators.
- `/src/components/DeveloperEmbedKit.tsx`: JavaScript, React, and Python SDKs for developers integrating the 50% trust badge.
- `/src/components/StakeholderPersonas.tsx`: Multi-perspective analytical simulator (Entrepreneurs, Creators, Consumers, Policy Makers).
- `/src/services/StripeDistributionService.ts`: Automated 50/50 revenue split calculation and webhook processor.
- `/src/services/masterPlanData.ts`: 7-phase civilizational metrics and technological milestone data.
